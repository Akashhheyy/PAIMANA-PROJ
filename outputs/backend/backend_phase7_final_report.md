## 12. Known limitations

- **No database**: CSV data is cached in process memory (read-only).
- Serves only the **April 2026 PAIMANA snapshot** — model-estimated
  associations, **not** verified future forecasts (prototype early warning).
- Same-model repeated predictions are byte-identical *on this machine*
  (see §7 result); float-serialization differences across platforms are not
  claimed to be impossible — hence documented rather than "fixed".
- No authentication, rate limiting, or deployment configuration.
- `n_jobs=1` inference chosen for repeatability documentation, not speed.

## 13. Backend readiness

**The backend is ready for database integration.** Architecture
(Route → Service → cached artifact) already isolates data access behind
`project_service` / `risk_service`; swapping the CSV readers for a
repository layer is the documented next phase. No database work, no model
work, and no frontend work were performed or started in Phase 7.
